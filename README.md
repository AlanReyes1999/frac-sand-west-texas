# frac-sand-west-texas

Un mod para Claude Code: fondo animado de un atardecer en el oeste de Texas con logística de frac sand, y colores de la aplicación a juego.

- Pumpjacks, mesas y una carretera con camiones de arena cargados y de regreso.
- Cuatro silos de arena cuyo nivel sube a medida que se llena la ventana de contexto (un paso por cada 5 %).
- De 2 a 12 camiones en la carretera según el contexto usado.

El fondo se dibuja en la app de escritorio y en la móvil; la terminal y los editores no lo muestran.

## Instalación

En el prompt de una sesión de terminal:

```
/plugin install frac-sand-west-texas --marketplace AlanReyes1999/frac-sand-west-texas
```

Responde `y` para agregar el marketplace y elige el alcance (usuario para todas tus sesiones).

Desde una shell:

```
claude plugin install frac-sand-west-texas --marketplace AlanReyes1999/frac-sand-west-texas
```

En la app de escritorio, donde `/plugin` no corre: clic en **+** junto a la caja de mensaje, luego **Plugins**, **Add marketplace** con `AlanReyes1999/frac-sand-west-texas` y **Add plugin**.
